# Demo 设计与检测说明

> 方向更新（2026-06-17）：本产品的核心是**资产管理**，记账只是其中一种录入方式。
> 参考真实的「有数 - 物品记账与个人资产管理」（资产全生命周期管理）后，demo 已从"记账为主"重做为"**资产管理为主**"。本文档以新方向为准；早期记账向的描述已作废。

应用：`demo/index.html`（单文件，纯静态 HTML + 内联 CSS + 原生 JS，无构建步骤）。浏览器直接打开，390px 移动端视口。

## 一、产品定位：资产管理为体，记账为用

- 实质目的：**管理"我有什么、值多少、还能用多久、值不值"**，而不是"这个月花了多少"。
- 资产范围：现金类 + 投资理财（占位）+ 实物（数码/家居/交通/腕表等）+ 权益票券（航段/礼品卡/会员/票券）。
- 交易降级：每笔变动挂在某个资产名下（改余额 / 用掉一段 / 续期 / 更新估值 / 标记已售），不做独立的大流水账。

## 二、借鉴真实「有数」的概念（原创落地，非照搬）

真实有数是资产全生命周期管理 app，招牌概念：
- **双主指标**：总资产净值 + **日均成本（¥X/天 = 原价 ÷ 已持有天数）**。
- **生命周期状态**：服役中 / 闲置 / 已退役 / 已卖出，顶部状态分布条。
- **物品卡 + 剩余进度**：总价 · 已用天数 · ¥X/天 · 进度条；变现盈亏复盘。

我们取其"概念与气质"，用**自有设计**落地（不抄它的霓虹绿/插画/版式）：
- 配色从早期冷灰蓝改为更温润的**玉/松石绿 + 暖中性纸面**，友好但克制、有辨识度。
- 自有签名组件：原创「**消耗刻度尺**」做剩余/进度；「**日均成本胶囊**」「**状态分布条**」作为资产管理专属表达。

## 三、设计 token（资产管理版）

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 纸面 paper | `#F3F5F0` | 暖中性背景 |
| 卡片 card | `#FCFDFA` | 卡片/物品卡表面 |
| 墨 ink | `#1C211D` | 主文字、数字 |
| 石灰 slate | `#5F6960` | 标签/次要（AA 对比） |
| 玉绿 green | `#2E7D5B` | 主色/正向/选中/剩余刻度 |
| 临期琥珀 amber | `#C77A12` | 临期/警示填充（文字态 `#8A5408`） |

字体：IBM Plex Sans（拉丁标题）/ Noto Sans SC（中文）/ IBM Plex Mono（金额、¥X/天、天数）。

## 四、信息架构（六屏，资产为纲）

- **总览**：总资产净值 + 日均成本（双主指标）+ 资产状态分布条 + 资产分组下钻（现金/投资[占位]/实物/权益）+ 待办摘要；可切"含非现金 / 仅现金"口径。
- **资产**：分类 tab（全部/现金/数码/家居/交通/腕表/权益）+ 状态筛选 chip（全部/服役中/闲置/临期/已退役）+ 物品卡（缩略/名称/总价·已用天数/¥X天/进度·状态）。
- **资产详情**：物品大图卡 + ¥X/天 + 持有进度 + 生命周期状态 + 资产信息 + 变动记录；动作=改余额/更新估值/用掉一段/续期/标记闲置/标记已售。
- **待办**：临期·续期·维护清单（资产不遗忘）。
- **＋ 动作**：添加资产（模板）/ 记一次变动（非"记一笔交易"）。
- **我的**：估值口径开关 + 设置；另含「投资」占位空状态页。

## 五、检测方式

Playwright 无头 Chromium 在 390×844 渲染各屏截图（`screenshots/`），并跑功能断言（净资产/日均成本计算、用掉一段递减、续期消临期、状态筛选、估值口径切换等）。详见 `tools/`（macOS 上从命令行运行可能需在「完全磁盘访问」中授权终端）。
