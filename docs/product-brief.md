# Product Brief: Held Ledger

## Goal

做一个轻量、清晰、好坚持的 local-first 个人资产台账，让用户理解自己持有什么、价值多少、使用多久，以及下一步需要处理什么。

这个产品不只记录钱，也要记录“类资产”和权益，例如航司航段、车辆、礼品卡、储值卡、会员权益、票券和其他有价值但不一定直接表现为现金余额的东西。

## Positioning

- 类型：个人或小家庭资产台账 + 记账工具
- 核心价值：快速记录、清楚复盘、减少生活资产和权益遗忘
- 目标体验：比表格更顺手，比传统记账软件更贴近日常生活

## Target Users

- 想养成记账习惯，但不想被复杂功能打断的人
- 希望看清每月钱花在哪里的人
- 有预算、储蓄目标或消费控制需求的人
- 需要按分类、账户、周期复盘收支的人
- 想统一管理现金、票券、会员权益、车辆和礼品卡等资产的人

## Core Scenarios

1. 记录一笔支出或收入
2. 查看今天、本周、本月的收支概览
3. 按分类查看消费结构
4. 设置预算并追踪剩余额度
5. 回顾月度账单和趋势
6. 管理多个账户或钱包
7. 记录一项非现金资产或权益
8. 查看资产清单、到期时间、剩余数量或可用余额
9. 追踪某类资产的使用记录，例如航段数量从 2 个减少到 1 个

## Asset Coverage

### Money-Like Assets

- 现金
- 银行卡余额
- 支付账户余额
- 储值余额
- 押金
- 借出/借入款

### Non-Cash Assets And Entitlements

- 航司航段：可记录总数、剩余数量、有效期和使用记录
- 车辆：例如车牌、购入价格、估值、保险、保养、年检、贷款或相关支出
- 礼品卡/储值卡：可记录面值、余额、有效期和消费记录
- 会员权益：例如酒店、航司、信用卡权益、兑换券、升舱券
- 票券：例如电影票、演出票、餐券、兑换码
- 贵重物品：例如电子设备、首饰、收藏品，可记录购买价、保修期、估值、图片
- 保单：例如车险、医疗险、寿险，可记录保额、保费、到期时间

## Initial Feature Scope

### Must Have

- 收入、支出记录
- 分类管理
- 金额、日期、备注、账户字段
- 资产/权益记录
- 数量、余额、有效期、状态字段
- 首页收支概览
- 资产清单入口
- 月度统计
- 分类占比图
- 预算进度
- 记录列表与筛选

### Should Have

- 常用分类快捷入口
- 周期性账单
- 多账户余额
- 非现金资产分类
- 到期提醒
- 使用记录
- 月度总结
- 搜索记录
- 数据导入/导出

### Later

- 家庭共享账本
- 智能消费建议
- 发票或截图识别
- 多币种
- 图片或凭证附件
- 资产估值历史
- 云同步

## Key Product Questions

- 先做移动端优先，还是桌面端也要完整体验？
- 是否需要登录和云同步？
- 分类体系是固定预设，还是允许用户完全自定义？
- 视觉风格、信息架构和功能组合中，哪一项最值得优先迭代？
- 是否只做日常资产台账、流水和预算，避免变成复杂理财工具？
- 非现金资产是否需要折算成总资产金额？
- 航段、礼品卡、票券这类权益是否统一叫“权益”，还是单独分组？
- 车辆这类长期资产是否需要维护保险、保养、年检等子记录？

## Non-Goals For First Build

- 不做复杂投资或理财组合管理
- 不做银行自动同步
- 不做多人权限系统
- 不做完整财税工具
- 不在第一版强制要求所有非现金资产都能自动估值
