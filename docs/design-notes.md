# Design Notes

## Reference Direction

参考“有数”类记账产品时，重点关注以下方向：

- 低摩擦录入：记一笔账要快，入口明确，字段不要过多
- 数据可视化：图表应帮助用户理解消费结构，而不是制造负担
- 月度视角：围绕“本月花了多少、还剩多少、钱去哪了”组织信息
- 分类清晰：分类图标、颜色和命名要稳定，方便形成记忆
- 情绪友好：钱和资产记录可能带来压力，文案和视觉应克制、清楚、不过度评判
- 资产不遗忘：除了钱，也要让用户记得自己有哪些航段、礼品卡、车辆、票券和会员权益

## Main Views To Plan Later

- Dashboard：今日/本月概览、预算进度、最近记录
- Add Transaction：快速录入收入或支出
- Records：流水列表、筛选、搜索
- Analytics：分类占比、趋势、周期对比
- Budgets：预算列表、分类预算、进度提醒
- Accounts：账户和余额管理
- Assets：非现金资产和权益清单
- Asset Detail：资产详情、余额/数量、有效期、使用记录、相关支出
- Settings：分类、自定义、导出、偏好设置

## Interaction Notes

- 录入流程优先减少点击次数
- 分类选择适合使用图标网格
- 金额输入应突出，备注和高级字段后置
- 首页要能一眼看到本月净收支、总支出和预算剩余
- 首页或资产页要能提醒快过期、快用完、需要维护的资产
- 资产录入要支持不同模板，例如航段、车辆、礼品卡、票券
- 图表不要喧宾夺主，结论比装饰更重要

## Asset Templates

### Flight Segment

- 名称：国航航段
- 数量：例如 2 个
- 剩余数量
- 航司
- 有效期
- 获取方式或购买成本
- 使用记录

### Vehicle

- 名称或车牌
- 购入价格
- 当前估值
- 保险到期日
- 年检时间
- 保养记录
- 相关支出

### Gift Card

- 名称：例如好利来礼品卡
- 面值
- 当前余额
- 有效期
- 卡号或备注
- 消费记录

## Visual Direction

- 整体应偏工具型、清爽、安静
- 避免过度营销感的首页
- 颜色可用于区分收入、支出、预算风险和分类
- 卡片只用于独立信息块，不要把整个页面堆成卡片墙
- 移动端优先考虑单手操作和底部主要导航
