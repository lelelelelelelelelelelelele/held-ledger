# Demo · 册页（生活资产 + 记账）

可运行的移动端 demo，单文件、无构建步骤。

## 打开

直接用浏览器打开 `index.html` 即可（按 390px 移动端视口设计；桌面端会居中显示为手机列）。需要联网加载 Google Fonts（IBM Plex Sans / Noto Sans SC / IBM Plex Mono），离线时回退到系统字体。

## 这是什么

参考「有数」体验的「生活资产 + 记账」工具，设计方向为「册页 · 静态账表」(Quiet Ledger)：冷灰蓝纸面、等宽数字右对齐、强调色仅承载语义（支出=墨黑、收入=账面蓝、临期/超支=深琥珀）。签名元素「消耗刻度尺」把 钱 / 数量 / 时间 三类资产统一成同一种「还剩多少」的读数。

## 六屏与可交互点

- 首页：本月净收支对账头、预算进度、需要处理的临期资产（带刻度尺）、最近记录
- 记一笔：支出/收入切换、自定义数字键盘录入、分类网格；**保存后真实入账并跳转流水**
- 流水：按日分组、筛选 chip、**实时搜索**（备注/分类/账户/金额）
- 分析：分类占比环形 + 近 6 月趋势 + 收支对比
- 资产：现金类总额 + 现金账户 + 非现金资产/权益（航段/礼品卡/车辆/票券/会员）
- 资产详情：深色卡 + 消耗刻度尺 + 资产信息 + 使用记录；**国航航段「记一次使用」剩余 2→1 并盖「已核销」印**
